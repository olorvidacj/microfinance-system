# frontend (Phase 14)

Web dashboard for the Client Services & Financial Transactions module.

- Stack: React + Vite + JavaScript (spec §23)
- Talks to the backend REST API (`backend/`) using the Supabase anon key for
  auth sessions and `/api/v1/*` for business operations.
- The legacy HOSCOMO demo still lives at the repository root and will be
  retired when this app replaces it in Phase 14.
- Scaffolded in Phase 14 per the agreed development order.
